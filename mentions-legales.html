Données collectées

  • Formulaire contact : prénom, email, message → finalité : répondre à la demande → conservation : 1 an → base légale : intérêt légitime.
  • Compte étudiant (mon-espace) : prénom, nom, email, téléphone, année d'étude, avatar → finalité : gestion des membres BDE, carte fidélité, annonces → conservation : durée de l'adhésion + 1 an → base légale : exécution du contrat d'adhésion.
  • Annonces : titre, description, prix, contact (email/tel/insta), photos → finalité : mise en relation entre étudiants → conservation : jusqu'à suppression par l'auteur → base légale : consentement.
  • Google Analytics 4 : données de navigation anonymisées (pages vues, durée) → finalité : mesure d'audience → conservation : 2 ans → base légale : consentement (bandeau cookies).
  • Newsletter : email et nom (optionnel) → finalité : envoi d'informations sur les événements et actualités du BDE → conservation : jusqu'à désinscription → base légale : consentement (opt-in explicite, désinscription en 1 clic dans chaque email).

  • Resend (USA) : envoi d'emails transactionnels. Transfert encadré par les Clauses Contractuelles Types.
